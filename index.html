Promptwise

Chrome Extension

Promptwise helps students write better AI prompts that encourage learning instead of having the AI do the work for them. It injects a widget into ChatGPT, Claude, Gemini, and Perplexity that intercepts a prompt before it's sent, scores it for clarity and effectiveness, and rewrites it into a learning-focused version that builds reasoning rather than producing a copyable assignment answer.

  • Manifest V3 extension with a background service worker and content scripts
  • Uses the OpenAI API to return a structured JSON score, rewritten prompt, and feedback
  • Extracts prompt text from pasted images so screenshots of questions get rewritten too
  • Resizable in-page panel with small, medium, large, fullscreen, and sidebar layouts

VetConnect

Real-time Web App

VetConnect is a peer-support platform where veterans can connect and help each other. Users create an account, message other members one-on-one in real time, and join community rooms for group conversations, with a profile page that tracks their VetConnect journey.

  • Live direct messaging and community rooms powered by Socket.IO
  • Sign-up / sign-in flow and profile editing backed by a REST API
  • Private conversations and report tools available in every room
  • Responsive interface built with Tailwind CSS

BuildIt

Team Leader & Back-End Developer

BuildIt is a cost-optimization platform for makers: upload a 3D model, label each part with a material, and get the most cost-effective way to build it from real store prices. I led a team of six and built the backend service that processes uploaded models, calculates mesh volumes, and estimates material costs.

  • FastAPI backend that parses .glb uploads and computes per-mesh volume with Trimesh
  • Matches each part to vendor pricing in a SQLite materials database
  • Puppeteer scrapers that collect product data from Home Depot and Lowe's
  • Three.js viewer for uploading, rotating, and labeling models in the browser
